展开：STEAM + CFG 与时间距离奖励的区别

STEAM 在 RLinf 中以帧对的时序进度学习 ensemble critic，保守聚合得到逐帧优势标签，再用于 CFG 策略训练。这里的工作重点是复现、真机数据适配与实验验证。人工接管用于采集数据，后续 STEAM + CFG 优化属于离线训练。

RynnValue 则以任务条件下的剩余时间为价值目标。我的早期探索参考这一思路，将时间距离与阶段进度联系起来研究密集反馈。两条路线分别记录，不把 RynnValue 写成 STEAM 的必要组成部分。

一种势函数表述为 Φ(s) = −d(s, goal)，奖励塑形项为 γΦ(s′) − Φ(s)。这里用于解释建模思路；实际训练细节与消融结果需以实验配置和日志为准。

NEXT QUESTIONS

下一步：让杯子换个位置，任务依然成立。

  1. 杯子位置泛化

    系统增采杯子不同位置与相对布局的示范及纠错片段，建立训练布局与未见布局的分离评测。

  2. 分阶段失败诊断

    区分面包夹取、入杯、杯子夹取与递送失败，定位感知、动作或阶段切换问题。

  3. 固定协议与消融

    在相同评测条件下比较 SFT、增加多目标数据、加入纠错数据以及 STEAM + CFG，补充样本数和分项指标。

  4. 奖励模型与在线学习

    继续验证时序进度信号在复杂任务中的作用，探索与真机在线交互训练的结合。

以上为后续计划，不代表已经完成的实验结果。
